# Prompts de trabajo para Codex

Orden sugerido:
1. **[Auditoría](01-auditoria-repositorio.md)**: mapa del código, regresión offline y oportunidades.
2. **[Instrumentación](02-instrumentacion-trazas.md)**: JSONL, trazas y tests.
3. **[Benchmark](03-benchmark.md)**: precisión, consistencia, errores y latencia.
4. **[Dashboard propio](04-dashboard-propio.md)**: FastAPI y web HTML/CSS/JS; **sin Streamlit**.
5. **[Seguridad](05-seguridad.md)**: controles, privacidad, pruebas de regresión.
6. **[EFT notebook](06-notebook-eft.md)**: evidencias ejecutables en Jupyter/Colab.

Los prompts se han preparado como instrucciones de desarrollo; no constituyen resultados de ejecución. **No correr todos de una vez**. Validar cada hito antes del siguiente.
