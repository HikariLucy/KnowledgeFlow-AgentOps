# Entregables y evidencias

## EP3 (según pauta disponible)

- [ ] Informe de **máximo cinco páginas**, Word/PDF, con referencias APA.
- [ ] Evidencia del conjunto de **al menos tres métricas** aplicadas.
- [ ] Análisis de errores, trazas y cuellos de botella.
- [ ] Capturas y demostración de dashboard funcional propio.
- [ ] Recomendaciones fundamentadas, redactadas por el equipo.
- [ ] Repositorio con README ejecutable, bocetos, código y tests.
- [ ] Enviar informe y enlace al repositorio vía AVA y correo docente.
- [ ] Preparar **10 min de exposición + 10 de preguntas** por pareja; participación equitativa.

## EFT (según PDF específico)

- [ ] Informe académico **PDF** con caso, prompts/RAG, arquitectura, agente, observabilidad, seguridad y fuentes.
- [ ] Código en formato **Jupyter notebook/Colab**.
- [ ] Dashboard y prototipo funcional listos para demostración.
- [ ] Defensa **individual**, máximo **10 minutos por estudiante**.
- [ ] Declaración de uso de IA.
- [ ] Reflexión personal individual y conclusiones redactadas sin IA.

## Evidencia mínima para el repositorio

`docs/evidencias-ep3/` puede contener capturas anonimizadas; `evaluation/agentops/` contendrá fixtures y resultados reproducibles. No subir logs de producción ni datos personales.
